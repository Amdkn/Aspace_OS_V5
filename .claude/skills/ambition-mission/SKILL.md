# Ambition Mission Compiler

Use the canonical contract at `00_Memoire/bundle/templates/ambition-mission-template.md`.

## Trigger

Invoke this workflow whenever the request includes multiple deliverables, system-level outcomes, cross-repository work, operations spanning sessions, architecture, integration, or a result whose next steps can be derived from existing context. For an atomic action, apply the four dimensions proportionately without creating unnecessary orchestration.

## Method

1. Read the root and nearest child DOX files, relevant OKF concepts, prior decisions, current Workgraph, source code and live system state.
2. Treat the user’s words as the outcome request, not as a requirement that the user author every expert prompt. Compile the specialist scope, methods, tools, agents, dependencies and acceptance tests.
3. Apply Speed, Altitude, Depth and Range simultaneously. Select real disciplinary methods; do not roleplay a crew.
4. Create or update a durable Mission Contract and Workgraph. Connect it to the parent goal; do not create a disconnected plan.
5. Dispatch independent work to real agents/workers and isolated worktrees. Preserve one writer per worktree and make reviewers read-only.
6. Execute immediately. After each validated result, activate the next unlocked work. Do not stop because a response, phase, ticket, commit or P0–P7 boundary has ended.
7. Obtain an Outside Judge independent from the creator. Prefer executable tests, CI, benchmarks, attesters and domain acceptance checks.
8. Persist all state required for resumption in Git remote or durable storage referenced by Git. Compute workers are disposable. Push commits and verify remote SHAs before treating work as durable.
9. If a real external authorization or irreversible decision is missing, isolate that decision and continue all independent work. Never fabricate access, proof, quota or 24/7 persistence.

## Exit

Do not return only a prompt, plan or report. Deliver the real outcome, integrated implementation, durable continuation state and independent proof. Keep the parent mission active until its complete acceptance criteria are satisfied.
