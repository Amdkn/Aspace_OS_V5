# 03_Videaste — 00_Repos_Category

Source : vidéo AI Labs « Insane GitHub Repos To Actually 10x Claude Video Editing » (https://www.youtube.com/watch?v=oTWUyW_bR-g), synthèse Gemini du 2026-11-04.

8 skills Claude Code pour la création et l’édition vidéo assistée par Claude. URLs vérifiées le 2026-11-04 (description de la vidéo + recherches) : 8/8.

## 1. Films de lancement

- **Hashu Motion** — repo : alchaincyf/huashu-motion — https://github.com/alchaincyf/huashu-motion — Clone ouvert de Claude Motion : films de lancement, musique calée sur le rythme, règles de réalisation.
- **Take One** — repo : talsiach/take-one — https://github.com/talsiach/take-one — Une idée texte jusqu’au film fini : stratégie, direction artistique, storyboard, montage, révision par agents indépendants.

## 2. Animation

- **Ross Ark Motion** — repo : rossark0/rossark-motion-skill — https://github.com/rossark0/rossark-motion-skill — Mascottes, illustrations, icônes et logos animés de façon naturelle et cohérente.
- **Reanimate** — repo : NiazMorshed2007/reanimate — https://github.com/NiazMorshed2007/reanimate — Clone les animations d’autres sites (vidéos, GIFs) et les reproduit fidèlement, comparaison image par image.

## 3. Démos et explicatifs

- **Argo** — repo : shreyaskarnik/argo — https://github.com/shreyaskarnik/argo — Navigue dans une application web, l’enregistre, puis produit une vidéo de démonstration avec voix off, zooms et surlignages.
- **Explain Roo** — repo : vincentsch/explainroo — https://github.com/vincentsch/explainroo — Vidéos explicatives et tutoriels synchronisés avec une voix off générée, sous-titres et miniatures.

## 4. Direction et son

- **Video Director** — repo : win4r/video-director — https://github.com/win4r/video-director — Claude en directeur artistique : supervision et automatisation des clips et reels, vérifications mobile, accessibilité et accroche.
- **Earshot** — repo : Leonxlnx/earshot — https://github.com/Leonxlnx/earshot — « Système auditif » de l’agent : son converti en texte lisible, synchronisation précise audio, effets et pics musicaux avec l’image. Par l’auteur de la compétence Taste.
