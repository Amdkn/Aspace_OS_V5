# Glossary & Ontology (Omni-Compiler)

| Terme | Définition & Rôle dans Aspace OS V5 |
|---|---|
| **Super-Skill** | Compétence synthétique unifiée combinant plusieurs sources expertes complémentaires (vidéos, livres, retours d'expérience) sous une interface procédurale unique avec arbitrage contextuel des divergences. |
| **Ingestion Multimodale Dual-Engine** | Architecture combinant l'analyse sémantique vidéo cloud (Gemini API à -87% de tokens) pour le repérage temporel et le moteur local souverain (WhisperX + I-Frames ffmpeg) pour l'inspection pixel-perfect d'interfaces. |
| **Geste Déictique** | Indication verbale du locuteur dans la vidéo pointant un élément d'écran précis (*« regardez ici »*, *« comme on le voit dans ce panneau »*). Déclenche automatiquement l'extraction de l'image exacte correspondante. |
| **Triage Épistémique (Comment vs Quoi)** | Séparation stricte entre les processus d'exécution reproductibles (encodés dans `.agents/skills/`) et les faits conjoncturels évolutifs (injectés dans `00_Memoire/bundle/` et le graphe MCP `memory.jsonl`). |
| **Bookshelf Progressive Disclosure** | Chargement hiérarchisé à la demande : la tranche (`SKILL.md`) au boot de l'agent (~100 tokens), les chapitres (`chapters/`) et fiches (`cheatsheet.md`) uniquement à l'exécution de la tâche. |
| **Équation de Valeur (Hormozi)** | Formule $V = \frac{\text{Résultat Idéal} \times \text{Certitude Perçue}}{\text{Délai} \times \text{Effort \& Sacrifice}}$, pivot pour packager les offres agentiques B2B sans guerre de prix. |
| **Matrice de Conscience (Schwartz)** | Les 5 degrés de réceptivité client (Non conscient -> Conscient du problème -> Conscient de la solution -> Conscient du produit -> Très conscient) régissant le ton et l'accroche de tout document produit. |
| **Protocole WRAP (Heath)** | Heuristique anti-complaisance forçant l'agent à élargir les options (W), confronter la réalité (R), prendre du recul (A) et anticiper l'erreur (P) face à tout choix stratégique. |
