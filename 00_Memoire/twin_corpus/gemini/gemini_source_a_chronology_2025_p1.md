# Génération de l’ossature de l’app A’Space – Galerie virtuelle 3D
## Contexte
A’Space est une plateforme immersive présentant 70 agents IA sous forme d’œuvres dans une galerie virtuelle. Chaque agent est identifié par une nomenclature fractale Sx-Ay-Fz-#n (S0→S3, A0→A3, Fz documents).
## Objectif
Créer, via Firebase Studio ou tout assistant IA de génération d’app, un **projet React** avec :
1. **React Three Fiber** configuré pour afficher une galerie 3D de corridors et salles.
2. **Firebase Auth** pour la connexion utilisateur.
3. **Firestore** configuré avec une collection `agents` hébergeant les métadonnées des œuvres.
4. **Cloud Functions** pour récupérer dynamiquement les agents selon Sx-Ay-Fz.
## Spécifications techniques
- **Structure de fichiers** :  
  - `src/firebase.js` : initialisation Firebase (Auth + Firestore).  
  - `src/components/Corridor.jsx` et `Room.jsx` : composants 3D (positions, maillage, textures).  
  - `src/components/AgentCard.jsx` : affiche un cadre flottant avec titre, image et bouton “Détails”.  
  - `src/components/PromptConsole.jsx` : zone de saisie “vibecoding” pour générer des composants à la volée.  
- **Conception UI** :  
  - Tailwind CSS pour le style minimaliste + néons.  
  - Typographie monospace pour les IDs, sans-serif pour le contenu.  
- **Navigation** :  
  - Contrôles clavier/mouse/touch pour se déplacer dans les couloirs (pitch, yaw, zoom).  
  - Hover/onclick sur `AgentCard` pour ouvrir un drawer latéral avec `{ name, role, promptTemplate, endpoint }`.
- **Firestore Rules** : restreindre lecture/écriture aux utilisateurs authentifiés.
## Livrables attendus
- Projet initial React + Firebase (package.json, firebase.js).  
- Composants `Corridor`, `Room`, `AgentCard`, `PromptConsole`.  
- Configuration Firestore (`agents` collection + règles).

- Démo hébergée sur Firebase Hosting, accessible à l’URL fournie par l’outil.
