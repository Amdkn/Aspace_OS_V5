:"### 1. Configuration de l'allocation RAM & Auto-boot WSL (16 Go)

sudo tee /etc/wsl.conf <<EOF

$action = New-ScheduledTaskAction -Execute "wsl.exe" -Argument "-d CoolEmbrl -u root exec /bin/true"

### 2. Arbitrage des Conflits de Ports : Coolify vs Umbrel OS

Coolify et Umbrel OS embarquent tous les deux un reverse proxy (Traefik ou Nginx) qui tente d'écouter sur les ports `80` et `443`. Lancer les deux simultanément sur la même stack Docker sans modification provoque une collision immédiate.

* **Stratégie recommandée** : Laisser Coolify contrôler les ports `80` et `443` (pour gérer les certificats SSL Let's Encrypt et le reverse proxy vers toutes les applications).
* **Décalage d'Umbrel OS** : Modifier le port web d'Umbrel pour le router sur le port local `8080`.
Dans le fichier d'environnement ou le `docker-compose.yml` d'Umbrel :
```env
APP_PORT=8080

```


L'interface locale d'Umbrel devient accessible via `http://localhost:8080`, et son URL interne peut ensuite être ajoutée dans Coolify comme une ressource de type *Service / Custom Docker Proxy* pour être routée vers un sous-domaine public.

### 3. Liaison avec le nom de domaine sur Hostinger

D'après le tableau de bord Hostinger, le domaine actif déposé est **`aspaceos.tech`** (valide jusqu'en octobre 2027).

Comme la machine est hébergée sur un PC local (souvent derrière une box avec IP dynamique ou CGNAT), deux méthodes d'exposition existent :

```
                        [ Internet / Requête Utilisateur ]
                                        │
                                        ▼
                       [ DNS Hostinger : aspaceos.tech ][cite: 5]
                                        │
                    ┌───────────────────┴───────────────────┐
                    ▼                                       ▼
        [ Option A : Tunnel Sécurisé ]          [ Option B : IP Publique Box ]
           Cloudflare Tunnel (cloudflared)         Redirection Ports Box 80/443
                    │                                       │
                    └───────────────────┬───────────────────┘
                                        │
                                        ▼
                          [ WSL2 : Instance CoolEmbrl ]
                                        │
                               ┌────────┴────────┐
                               ▼                 ▼
                       [ Coolify : 443 ]   [ Umbrel : 8080 ]

```

#### Option A : Cloudflare Tunnel (Recommandée — Sans ouverture de ports sur la box)

1. Créer un tunnel dans Cloudflare Zero Trust (ou installer `cloudflared` dans l'instance WSL `CoolEmbrl`).
2. Router :
* `coolify.aspaceos.tech` $\rightarrow$ `http://localhost:8000` (interface Coolify)
* `umbrel.aspaceos.tech` $\rightarrow$ `http://localhost:8080` (interface Umbrel)
* `*.aspaceos.tech` $\rightarrow$ `http://localhost:80` (proxy Traefik Coolify pour les apps déployées)


3. Côté Hostinger, dans la gestion DNS de `aspaceos.tech`, faire pointer les serveurs de noms (NS) vers Cloudflare, ou ajouter des enregistrements `CNAME` pointant vers l'URL du tunnel.



#### Option B : Redirection directe Box + DNS Hostinger

1. Fixer l'adresse IP locale du PC dans le DHCP de la box internet (ex: `192.168.1.50`).
2. Rediriger les ports `80` et `443` de la box vers l'IP locale du PC.
3. Dans WSL, configurer la passerelle ou activer le mode réseau en miroir dans `.wslconfig` :
```ini
[wsl2]
networkingMode=mirrored

```


4. Dans le panneau Hostinger > **Domains** > **Manage** sur `aspaceos.tech` > **DNS / Nameservers** :


* Ajouter un enregistrement **A** : `@` pointant vers l'IP publique de la box.
* Ajouter un enregistrement **A** : `*` pointant vers la même IP publique.
